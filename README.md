# Практическая работа №3. Автоматизация технического сопровождения ИС с помощью скриптов командной строки (.bat)

## 🎯 Техническое задание:
В рамках регламентного обслуживания интегрированной системы вам необходимо написать скрипт резервного копирования критических конфигураций.

### 📋 Требования к скрипту `backup.bat`:
1. Скрипт должен создать в корне репозитория новую папку с именем `archive`.
2. Скрипт должен сгенерировать текстовый файл по пути `archive/status.log`.
3. Внутрь файла `status.log` скрипт должен записать строку: `Резервное копирование успешно завершено`.

---

## 🤖 Как сдавать работу:
1. Создайте ветку `dev` в GitHub Desktop.
2. Реализуйте логику команд внутри созданного файла `backup.bat`.
3. Сделайте `Commit` и `Push` в ветку `dev`.
4. Откройте Pull Request на сайте GitHub из ветки `dev` в ветку `main`.
5. Убедитесь, что автоматический тест (Actions) запустился на сервере и загорелся **зеленым цветом**.
